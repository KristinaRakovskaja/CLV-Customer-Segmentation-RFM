This repository contains two data analytics projects focused on customer behavior analysis. 

The **CLV (Customer Lifetime Value)** file includes cohort-based analysis to estimate the long-term value of users and identify trends in spending over time. 

The **Customer Segmentation and RFM** file uses Recency, Frequency, and Monetary value metrics to segment users into meaningful groups for targeted marketing strategies. Together, these projects provide actionable insights to improve customer retention and optimize marketing efforts.
